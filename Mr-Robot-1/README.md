# Mr-Robot: 1 — VulnHub

## Overview
Mr-Robot: 1 is an intentionally vulnerable virtual machine from VulnHub. This repository documents my penetration-testing process, findings, and evidence from the lab.

## Lab Environment
- **Attacker:** Kali Linux
- **Target:** Mr-Robot: 1
- **Virtualization:** Oracle VirtualBox
- **Tools:** Nmap, Gobuster, Hydra, Metasploit

## Methodology
1. Reconnaissance and port scanning
2. Web application enumeration
3. Credential testing
4. WordPress administration access
5. Initial access and shell handling
6. Privilege escalation
7. Flag retrieval and documentation

## Key Findings
- Information disclosure through exposed web content
- Weak WordPress authentication
- Risk associated with privileged PHP file editing
- A privilege-escalation path leading to root access

## Evidence
Screenshots and the penetration-testing report document the assessment process and results.

## Disclaimer
This assessment was conducted in an intentionally vulnerable lab environment for educational purposes. Only test systems that you own or have explicit permission to assess.
