# VulnHub Boxes

A hands-on penetration-testing portfolio documenting my independent assessments of intentionally vulnerable virtual machines.

This repository records my approach to reconnaissance, service enumeration, vulnerability identification, initial access, privilege escalation, and remediation. The goal is to develop practical penetration-testing skills through structured, evidence-based assessments.

## Objectives

- Develop a systematic methodology for assessing vulnerable systems.
- Improve service enumeration and vulnerability analysis.
- Understand how misconfigurations and exposed services can lead to system compromise.
- Practise Linux enumeration and privilege escalation.
- Document findings with supporting evidence and remediation recommendations.
- Build a portfolio demonstrating practical penetration-testing skills.

## Lab Environment

| Component | Details |
|---|---|
| Attacker machine | Kali Linux |
| Virtualisation | Oracle VirtualBox |
| Target machines | Intentionally vulnerable VulnHub virtual machines |
| Network configuration | Isolated host-only lab network |
| Primary tools | Nmap, Netcat, Hydra, SMB utilities, FTP clients, and other tools as required |

Tools are selected according to the services and potential attack paths discovered during each assessment.

## Learning Approach

I am using these machines to strengthen my ability to solve unfamiliar targets independently.

For each assessment, I aim to:

1. Begin with reconnaissance rather than a predefined exploit.
2. Enumerate services systematically.
3. Form hypotheses based on evidence.
4. Validate findings instead of assuming that a possible vulnerability is exploitable.
5. Document failed approaches and useful observations.
6. Explain the complete attack path and recommend appropriate fixes.

Where external references or walkthroughs are consulted, I aim to distinguish that assistance from work completed independently.
